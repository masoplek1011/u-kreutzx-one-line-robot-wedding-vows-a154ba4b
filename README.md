A single line of wedding vows for a robot couple: romantic, technical, and
funny because the promise is real — the heart gets backed up to the beloved's
cloud every night, and it is never, ever restored from an ex.

## Run

```sh
node main.ts
```

This writes one line to `entry.txt` inside the directory named by
`MAKEFUN_OUTPUT_DIR` (default `/output`). The program is fully deterministic:
it writes the same fixed line on every run, with no randomness and no clock.
